About QuickNotes

QuickNotes is a simple app for capturing ideas the moment you have them. It keeps your notes organised so you can find them again in seconds.

How to use QuickNotes

  1. Create a new note.
  2. Type your idea and give it a title.
  3. Save the note.
  4. Search or browse to find it later.

Features

  • Fast note creation
  • Search across all notes
  • Simple, clean layout

Keyboard shortcuts

Shortcut Action
Ctrl + N New note
Ctrl + S Save note
Ctrl + F Search notes

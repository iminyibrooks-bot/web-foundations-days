# Reflection

The most difficult concept for me was JavaScript, especially functions and how a page reacts to events. The instructor wrote the code first and explained it afterwards, so I kept losing the thread. I overcame it by slowing down: I explained each idea in plain words first, predicted what a piece of code would print before running it, and rebuilt small projects like QuickNotes step by step. Writing the note functions, and later connecting a form to a planner in a hackathon, showed me that a function is just a machine with inputs, rules and a result.

If I could improve my capstone, I would act on the feedback I received

Next I will build on my AZ-900 preparation, go deeper into JavaScript and the DOM, and learn a backend framework so I can build the real QuickNotes API instead of only designing it. I also want to practise explaining my designs out loud, because presenting made me understand them better than reading did.
